# Preview credits and evidence

Talk Me Home extends AssemblyAI's voice-agent-starter-js:
https://github.com/AssemblyAI/voice-agent-starter-js
The repository retains its upstream files and notices. This media package does not add a license grant for upstream code or claim ownership of AssemblyAI's trademarks.

Pip, the station illustrations, diagrams and interface are project-authored artwork. The cover is the unchanged Goal 006 illustration. Screenshots and the Goal 007 preview show actual deterministic Practice gameplay; source identities and hashes accompany them. No stock character, external sound track, purchased asset or generated substitute gameplay is used.

The preview's presentation narration was synthesized locally with the installed Microsoft Zira Desktop voice. It is labelled separately from game dialogue and does not impersonate Pip or represent human speech. The movie contains no current AssemblyAI Voice acceptance evidence. Its captions preserve the distinction between narration and on-screen Practice dialogue.

The game uses React, React DOM and Scheduler. Their distribution notices are included verbatim in `third-party-notices.txt`. Browser output and synthetic/digital audio checks do not establish physical-speaker quality, human enjoyment or statistical reliability.

The local preview package has not been uploaded or submitted. Public HTTPS, current hosted Voice acceptance, reviewer enablement and source disclosure remain separate pending release gates.
