## Implemented coordination repair

Ordinary speech still flushes playback, stops stale uncommitted work, advances the action epoch, and preserves interrupted-caption provenance. It uses the existing `supersede` cancellation reason, so an early speech-start notification does not itself revoke a prepared return grant. A current provider `reply.done` with `status: interrupted`, explicit Interrupt, Pause, Restart, and End retain their cancellation authority. An older reply's delayed interruption cannot cancel a newer reply.

Known pending calls retain their original identity and eventual verified outcome after local cancellation. An actual committed success can be returned once at a safe completed-turn boundary; canceled arguments are never executed again. Calls definitely canceled before dispatch receive `cancelled_before_execution`. A dispatched action whose outcome cannot be verified receives `outcome_unknown`, never an invented rollback or equipment failure. Verified negative local results use `precondition_failed`. The provider's outer `tool.result` remains unchanged, and only allowed `ok`, `message`, and recognized outcome code fields enter its JSON result. Human projections and private state are excluded.

Results wait while the player is speaking and across replacement cancellation barriers. Both ordinary reply IDs and documented `fc-<call_id>` completions are covered, including completion arriving before the tool call. A completion window is invalidated by a new speech/reply transition; ambiguous correlation cannot authorize execution. Any unresolved call has a 15-second local recovery deadline that initiates visible shutdown and requires explicit reconnection. The adapter may then wait up to five seconds for termination. These are application bounds, not provider timing guarantees. The existing ten-second HTTP action bound remains unchanged.

`SessionStore` still validates round, chapter and action epoch at commit and owns idempotency. The authoritative tests exercise real session actions and both orders of commit/cancellation. Artwork, runtime prompt, inline configuration, transcription mode, silence thresholds, puzzle rules, and public instrumentation were not changed.
