# Archived starter deployment

`render.pre-goal007.yaml` is the byte-preserved root starter manifest from before Goal 007. It is historical and must not be applied as the game deployment. Its original `npm start` command predates the product-first main entry point.

Run the preserved local starter explicitly with `npm run start:starter`. Publishing/importing agents and telephony remain separate starter utilities. The game's canonical root `render.yaml` uses `npm run build:game` and `npm run start:game`.
